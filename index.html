InkDOS Hub Alpine Linux
Alpine Linux 3.21 (x86-64) on InkSoC, our own engine: it plays the part of the Linux kernel, like WSL 1, and runs Alpine's real programs. The first start creates your user and password. Your files are kept in this browser between visits. Type help for the guide. Network: wisp = a public wisp server (the one used by v86 Linux terminals), or none. Memory follows InkSoC: programs see 8 GB, the real RAM in use is half of this device's limit (Calibrate memory), and the rest goes to a swap file in this browser. The ☰ menu sends files to your home folder and downloads them. BusyBox is GPL-2.0 (busybox.net); Alpine's packages keep their own licenses (alpinelinux.org).
