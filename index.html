InkDOS Hub Alpine Linux
Alpine Linux 3.21 (x86-64) on InkSoC, our own engine: it plays the part of the Linux kernel, like WSL 1, and runs Alpine's real programs. The first start creates your user and password. Your files are kept in this browser between visits. Type help for the guide. Network: wisp = a public wisp server (the one used by v86 Linux terminals), or none. Memory follows InkSoC: programs see 8 GB, the real RAM in use is half of this device's limit (Calibrate memory), and the rest goes to a swap file in this browser. The ☰ menu sends files to your home folder; ☰ Files shows them and saves them to this device; ☰ Store installs WebAssembly programs (python3, ruby). Mount a folder shows a folder of this device (iCloud Drive, On My iPad, a disk) at /mnt/NAME: programs read its files when they open them, and what they change or create goes back into the real folder within two seconds (where the browser lets a page write to folders; otherwise the folder is read-only and ☰ Files brings results out). BusyBox is GPL-2.0 (busybox.net); Alpine's packages keep their own licenses (alpinelinux.org).
